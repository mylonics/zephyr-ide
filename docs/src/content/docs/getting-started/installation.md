To get started, install the extension from [Visual Studio Code marketplace](https://marketplace.visualstudio.com/items?itemName=mylonics.zephyr-ide) or [Open VSX Registry](https://open-vsx.org/extension/mylonics/zephyr-ide)

## Next Steps

After installation, you'll want to:

1. [Open the Setup Panel](setup-panel.md) to configure your environment
2. [Install Host Tools](host-tools.md) required for Zephyr development
3. [Configure your Workspace](workspace-configuration.md) to manage Zephyr projects
4. [Install the Zephyr SDK](sdk-installation.md) for cross-compilation support
